# Search presence (SEO)

Goal: when someone searches **Lessy**, **Lessy Mpoe**, **Finehas Mpoe** or **Lessy Prospergenics**, lesiamon.com is the first result, and Google understands that Lessy is a co-founder of Prospergenics.

Nobody can guarantee a #1 ranking. What we control is the on-site half (done and tested here) and the off-site half (the checklist below, which needs your logins).

## What the site does on its own

- One address per thing: `/`, `/about`, `/services`, `/faq`, `/contact`, `/privacy`, `/projects` and one page per project (`/projects/<id>`). Each has a unique title, description, canonical address, Open Graph and Twitter tags.
- Structured data (JSON-LD): Person "Lessy Mpoe" (also known as Lessy, Finehas Mpoe), Organization Prospergenics, WebSite, ProfilePage, FAQPage, Service, CreativeWork, BreadcrumbList.
- `sitemap.xml`, `robots.txt`, `llms.txt` (summary for AI assistants), `www` redirects permanently to the main address.
- Pages are generated by `npm run pages` from `dist/projects.js`, `dist/socials.js` and `scripts/build-pages.mjs`. Never edit generated pages by hand. Run `npm run pages` after changing a project, then commit the result. `tests/unit/seo.test.mjs` fails if anything drifts.

## Do these once (needs your accounts)

1. **Google Search Console** → Add property → *Domain* → `lesiamon.com`. Add the TXT record in Cloudflare DNS. Then *Sitemaps* → submit `https://lesiamon.com/sitemap.xml`. Use *URL inspection → Request indexing* on `/`, `/about`, `/projects`.
   - Alternative: choose *URL prefix* and put the meta token in `seo.config.json` (`googleVerification`), run `npm run pages`, ship.
2. **Bing Webmaster Tools** → import from Search Console (one click). This also feeds DuckDuckGo and Copilot.
3. After each deploy that changes pages: `npm run indexnow` (pings Bing and Yandex).
4. **Link to the site from every profile you own**, always with the name "Lessy":
   - Prospergenics member page (`prospergenics.com/members/lessy/`): ask Martien to add a link to https://lesiamon.com. This is the single most valuable link, because it also ties you to the company.
   - GitHub profile (name "Lessy Mpoe", website field), LinkedIn (headline and website), Instagram, X, TikTok, Facebook, Reddit bios.
   - Add a Google Business-style "About" on each repo README that links back.
5. Use the same name and bio everywhere. Suggested bio:
   > Lessy (Finehas Mpoe), software developer and WordPress specialist. Co-founder at Prospergenics. lesiamon.com

## Keep it working

- Publish something real regularly (a case study, a short write-up per project). Search engines reward fresh, specific pages more than anything clever.
- Get other sites to mention you: client sites you built (a "Website by Lessy" credit linking to lesiamon.com), talks, Prospergenics posts.
- Measure in Search Console: impressions and clicks for "lessy", "finehas mpoe", "lessy prospergenics". Check weekly for the first two months. New sites usually take a few weeks to settle.
- Do not buy links or use keyword stuffing. It gets sites removed.
